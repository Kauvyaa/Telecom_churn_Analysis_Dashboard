📊 Telecom Customer Churn Analysis Dashboard

📌 Project Overview
Interactive data analytics dashboard to analyze telecom customer churn
Focuses on customer behavior, retention, and revenue loss
Provides insights using visual reports and KPI indicators
Helps businesses take data-driven decisions to reduce churn

🎯 Objectives
Analyze customer churn and retention patterns
Identify high-risk customers based on tenure and contract type
Understand the impact of services and payment methods on churn
Evaluate revenue loss caused by customer attrition
Discover key factors affecting customer loyalty

📊 Features
Dynamic dashboard with interactive filters (Contract, Payment Method, Internet Service, Churn Status)
KPI cards showing Total Customers, Active Customers, Churned Customers, and Churn Rate
Visualizations for churn distribution and customer segmentation
Contract Type vs Revenue Lost analysis
Tenure group analysis to identify churn trends
Demographic insights (Gender, Senior Citizen)

🛠️ Tools & Technologies
Power BI – Dashboard creation and visualization
Power Query – Data transformation and preparation
DAX (Data Analysis Expressions) – Measures and calculations

🧹 Data Preparation
Cleaned and transformed raw dataset using Power Query
Handled missing and inconsistent values
Standardized categorical columns (Contract Type, Payment Method, etc.)
Created calculated columns (Tenure Groups)
Built DAX measures for KPIs and analysis

📈 Key Insights
Month-to-Month contract customers show the highest churn
Customers with shorter tenure (0–12 months) are more likely to churn
Flexible contract types contribute to higher revenue loss
Certain payment methods are associated with higher churn rates
Long-term contracts improve customer retention

🚀 How to Use
Open the Power BI dashboard file (.pbix)
Use slicers to filter by contract type, churn status, and services
Explore visuals to analyze trends and patterns
Use insights for decision-making and strategy planning

📌 Conclusion
Power BI dashboard provides a clear view of customer churn behavior
Helps identify high-risk customers and revenue leakage
Supports data-driven strategies to improve retention and business performance
