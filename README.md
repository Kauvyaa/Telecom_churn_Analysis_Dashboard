# 📡 Telecom Churn Analysis Dashboard

## 📌 Project Overview

This project presents an interactive Power BI dashboard to analyze telecom customer churn, focusing on customer behavior, retention, and revenue loss. It provides actionable insights through visual reports and KPIs to support data-driven decisions.

## 🎯 Objectives

* Analyze customer churn and retention patterns
* Identify high-risk customers based on tenure and contract type
* Understand the impact of services and payment methods on churn
* Evaluate revenue loss due to customer attrition
* Discover key factors affecting customer loyalty

## 📊 Features

* Interactive dashboard with filters (Contract, Payment Method, Internet Service, Churn Status)
* KPI cards: Total Customers, Active Customers, Churned Customers, Churn Rate
* Visualizations for churn distribution and customer segmentation
* Contract Type vs Revenue Lost analysis
* Tenure group analysis for churn trends
* Demographic insights (Gender, Senior Citizen)

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard creation and visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and KPI calculations

## 🧹 Data Preparation

* Cleaned and transformed dataset using Power Query
* Handled missing and inconsistent values
* Standardized categorical columns
* Created calculated columns (Tenure Groups)
* Built DAX measures for KPIs and analysis

## 📈 Key Insights

* Month-to-Month contract customers show the highest churn
* Customers with shorter tenure (0–12 months) are more likely to churn
* Flexible contract types lead to higher revenue loss
* Certain payment methods are linked to higher churn rates
* Long-term contracts improve customer retention

## 🚀 How to Use

1. Open the Power BI (.pbix) file
2. Use slicers to filter by contract type, churn status, and services
3. Explore visuals to analyze trends and patterns

## 📌 Conclusion

This dashboard helps identify high-risk customers, understand churn behavior, and reduce revenue loss through data-driven strategies.
